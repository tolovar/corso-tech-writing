# Corso di Technical Writing

Benvenuto al corso pratico di **Technical Writing** – impara a creare documentazione tecnica chiara, strutturata e professionale.

## Cosa imparerai

- Principi fondamentali della scrittura tecnica
- Come strutturare documenti per massima comprensibilità
- Adattare tono e stile al pubblico di riferimento
- Creare diverse tipologie di documentazione
- Utilizzare l'AI come supporto alla scrittura

Questo sito viene pubblicato automaticamente tramite **GitHub Actions**. Ad ogni push sul branch `main`, la pipeline:

1. Scarica il codice sorgente
2. Configura l'ambiente Python
3. Installa MkDocs Material
4. Compila e pubblica il sito su GitHub Pages
